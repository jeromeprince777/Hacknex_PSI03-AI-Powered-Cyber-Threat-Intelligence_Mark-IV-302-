# ThreatWeave

Evidence-first AI-powered Cyber Threat Intelligence for reconstructing coordinated attacks from security logs.

## Problem

Security events can look benign individually but suspicious when correlated across users, devices, IPs and applications.

ThreatWeave converts raw logs into:
- an attack timeline;
- linked entities;
- multi-stage attack reconstruction;
- evidence for every stage;
- an explainable Risk Index;
- recommended response actions;
- bounded AI analyst explanations.

## Architecture

```text
Logs → Normalize → Signals → Entity Graph → Correlation
                                   ↓
                            Risk + Evidence
                                   ↓
                           Verified AI Copilot
                                   ↓
                              Analyst UI
```

## Canonical attack scenario

The seeded scenario contains:
1. unusual login relationship;
2. unusual resource access;
3. removable-media activity;
4. optional outbound-transfer enrichment.

The system should reconstruct the events as one ordered chain.

## False-positive scenario

The benign dataset contains routine administrator activity.

Expected result:
- no high-confidence incident.

## Evidence model

Every detected stage references event IDs.

## AI guardrails

The AI copilot:
- receives an evidence pack;
- cannot create event IDs;
- cannot introduce unknown entities;
- can recommend only approved actions;
- is verified before its answer is marked trusted.

## Limitations

The MVP:
- is designed for sample/controlled log formats;
- uses a configurable, explainable detection strategy;
- does not automatically change endpoint state;
- does not claim that the Risk Index is a probability;
- should be evaluated against representative logs before operational deployment.

## MVP vs Stretch

### MVP
- one multi-stage attack;
- benign baseline;
- evidence-linked stages;
- graph;
- timeline;
- Risk Index;
- AI explanation with verification.

### Stretch
- more attack families;
- live streams;
- analyst feedback;
